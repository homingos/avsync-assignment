# Submissions

One folder per person, named exactly as your GitHub username:

```
submissions/YOUR_GITHUB_USERNAME/
  predictions.json     your answers for every clip in data/heldout/
  run.py               (or run.sh) regenerates predictions.json from the clips
  METHOD.md            1-2 pages: what you did and why
```

Open one pull request containing only your own folder. See the main README for
the answer format and the full walkthrough.
